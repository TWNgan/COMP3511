⚡ 最易失分嘅 10 件事

  1. Response time（本科）= 第一次運行「完結」− arrival（slide 5.12），唔係第一次開始。
  2. MLFQ：被 preempt 嘅 Q1/Q2 job 返 queue HEAD，保留剩餘 quantum；只有用晒 quantum 先降級。
  3. fork() 返回值：child = 0、parent = child PID、失敗 = −1；&& / || 短路。
  4. exec() 成功唔會 return（之後嘅 printf 唔會印）。
  5. Mode bit：1 = user，0 = kernel；privileged instruction 喺 user mode → trap。
  6. DMA 完成一個 block 先 interrupt 一次（唔係每個 byte）。
  7. Named pipe 要 explicitly delete；ordinary pipe 要 parent–child、單向。
  8. Amdahl：S = serial portion（題目畀 parallel % 要轉換）；N→∞ speedup → 1/S。
  9. RM = static（period 短 = 高）；EDF = dynamic（deadline 早 = 高）；soft RT miss 咗都繼續跑。
  10. Semaphore 填空題冇用嘅 blank 要寫 /* Nothing */；test_and_set / CAS 返回 old value。
