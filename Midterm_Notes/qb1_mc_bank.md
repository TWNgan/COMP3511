## [S26-MC10] ch3 | fork count
```c

   int i;
   for (i = 0; i < 3; i++) {
      if (fork() == 0) {
         fork();
         printf("X ");
         return 1;
      }
   }
   printf("Y ");
   return 0;
}
```
What is the total number of processes (including the original), the number of "X " printed, and the number of "Y " printed?
- A. Total processes = 4, "X " = 3, "Y " = 1

## [S26-MC23] ch6 | Mutex + semaphore output
```c
int counter = 0; pthread_mutex_t mtx; sem_t sem;   /* sem_init(&sem, 0, 0) */
void *worker1(void *arg) { pthread_mutex_lock(&mtx); counter = counter + 2;
    printf("A %d;", counter); pthread_mutex_unlock(&mtx); sem_post(&sem); return NULL; }
void *worker2(void *arg) { sem_wait(&sem); pthread_mutex_lock(&mtx); counter = counter + 3;
    printf("B %d;", counter); pthread_mutex_unlock(&mtx); return NULL; }
/* main creates t1 (worker1) and t2 (worker2), then joins both */
```

- A. A 2; B 5;
- B. B 3; A 5;
- C. A 3; B 5;
- D. B 2; A 4;

**Answer: A**

解：sem 初始 0 → worker2 一定等 worker1 `sem_post` → 先 A（0+2=2）後 B（2+3=5）。

## [Lab4-MC] ch4 | Threads share memory, processes do not
```c
void *child(void *arg) { int *counter = (int *) arg; (*counter)++; return NULL; }
int main() {
    int counter = 0;  pthread_t thread;
    pthread_create(&thread, NULL, child, (void *)&counter);
    pthread_join(thread, NULL);
    printf("%d\n", counter);
    counter = 0;
    pid_t pid = fork();
    if (pid) wait(NULL);
    else { child((void *)&counter); exit(0); }
    printf("%d\n", counter);
}
```
What is the output?
- A. 0 then 0
- B. 1 then 0
- C. 0 then 1
- D. 1 then 1

**Answer: B**

解：thread 同 main 共用 `counter` → 印 1；fork 出嚟嘅 child 改嘅係自己嗰份 copy → parent 印 0。**Threads share memory space, processes have separate memory spaces.**（Lab 4）
