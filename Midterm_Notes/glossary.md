# Glossary A–Z（術語速查：英文定義可直接抄）

| Term | Definition（exam English） | 中文 | Ref |
|---|---|---|---|
| Accounting information | PCB field: CPU used, clock time elapsed, time limits | 記帳資訊 | 3.10 |
| Address space | The memory a program executes in, distinct from other programs' (text, data, heap, stack) | 位址空間 | 3.4–3.5 |
| Admission control | Real-time scheduler admits a task only if it can guarantee its deadline | 准入控制 | 5.48 |
| Aging | Gradually increasing the priority of a process that waits a long time, to prevent starvation | 老化 | 5.25 |
| Amdahl's Law | $\text{speedup} \le \frac{1}{S + (1-S)/N}$; as $N \to \infty$, speedup $\to 1/S$ | 阿姆達爾定律 | 4.12 |
| API | A set of functions available to programmers (parameters + return values) that invoke system calls on their behalf | 應用程式介面 | 2.15 |
| Asymmetric multiprocessing (AMP) | Master processor handles scheduling, I/O and kernel data; others run user code only; master may bottleneck | 非對稱多處理 | 1.37, 5.38 |
| Asynchronous cancellation | Terminates the target thread immediately | 非同步取消 | 4.32 |
| Asynchronous signal | Signal generated by an event external to the running process (Ctrl-C, timer expiry) | 非同步信號 | 4.29 |
| Atomic | Non-interruptible; executes as one uninterruptible unit | 原子性 | 6.14 |
| Atomic variable | Provides atomic updates on basic data types (e.g., increment via CAS) | 原子變數 | 6.21 |
| Average access time | Hit ratio × hit time + miss ratio × miss time | 平均存取時間 | 1.32 |
| Binary semaphore | Semaphore whose value is only 0 or 1; can act like a mutex | 二元信號量 | 6.25 |
| Blocking (synchronous) send/receive | Sender blocks until the message is received; receiver blocks until a message is available | 阻塞式 | 3.62 |
| Bootstrap program | First program run at power-on, stored in EEPROM | 開機程式 | 1.30 |
| Bounded buffer | Fixed-size buffer shared by producer and consumer | 有界緩衝區 | 3.53 |
| Bounded waiting | A bound exists on how many times others may enter their CS after a process requests entry | 有限等待 | 6.11 |
| Busy waiting | Looping continuously while waiting for a condition; wastes CPU | 忙碌等待 | 6.22 |
| Cache | Faster, smaller storage holding a copy of a subset of slower, larger storage | 快取 | 1.32 |
| Cascading termination | When a process terminates, all its children are also terminated by the OS | 級聯終止 | 3.48 |
| Chip multithreading (CMT) / hyperthreading | Multiple hardware threads per core, each appearing as a logical CPU; hides memory stalls | 晶片多執行緒 | 5.40–5.42 |
| clone() | Linux call creating a task that shares selected resources with its parent (flags) | 複製 | 3.46, 4.38 |
| Cloud computing | Delivers computing, storage and apps as a service over a network; extension of virtualization | 雲端運算 | 1.47 |
| Compare-and-swap (CAS) | Atomically: if *value == expected set *value = new; return original value | 比較並交換 | 6.17 |
| Concurrency | More than one task making progress (possibly by time multiplexing on one core) | 並行（並發） | 4.9 |
| Context switch | Saving the state of the old process/thread and loading the saved state of the new one; pure overhead | 上下文切換 | 3.20 |
| Convoy effect | Short processes stuck waiting behind a long process (FCFS) | 護航效應 | 5.10 |
| Cooperating process | A process that can affect or be affected by other processes | 協作進程 | 3.51 |
| Copy-on-write (COW) | Parent and child share pages until one writes; then the page is copied | 寫入時複製 | 3.46 |
| CPU burst | A period of CPU execution between I/O waits | CPU 爆發 | 5.4 |
| CPU-bound process | Spends most time computing; few long CPU bursts | CPU 密集 | 3.14 |
| CPU scheduler (short-term) | Selects a process from the ready queue and allocates a CPU core | 短期排程器 | 3.17, 5.6 |
| CPU utilization | Fraction of time the CPU is busy | CPU 使用率 | 5.8 |
| Critical section | Code segment in which shared data is accessed/modified | 臨界區 | 6.9 |
| Data parallelism | Same operation on different subsets of data across cores | 數據並行 | 4.11 |
| Deadlock | Two or more processes wait indefinitely for an event only one of the waiting processes can cause | 死結 | 6.28 |
| Deferred cancellation | Target thread periodically checks whether it should terminate (orderly) | 延遲取消 | 4.32 |
| Degree of multiprogramming | Number of processes currently in memory | 多道程式度 | 3.14 |
| Deterministic modeling | Evaluates algorithms on a predetermined workload; exact but specific | 確定性建模 | 5.54 |
| Device driver | Kernel module that controls a device | 裝置驅動程式 | 1 (summary) |
| Direct communication | Processes name each other explicitly; one link per pair | 直接通訊 | 3.59 |
| Dispatch latency | Time for the dispatcher to stop one process and start another | 分派延遲 | 5.7 |
| Dispatcher | Gives CPU control to the selected process: context switch, switch to user mode, jump to restart location | 分派器 | 5.7 |
| DLL (dynamically linked library) | Library loaded when needed and shared by all programs using it | 動態連結庫 | 2.31 |
| DMA | Controller transfers blocks directly between device and memory without CPU; interrupts once when done | 直接記憶體存取 | 3.25 |
| Dual-mode operation | User mode vs kernel mode distinguished by a hardware mode bit (1 = user, 0 = kernel) | 雙模式 | 3.27–3.28 |
| dup / dup2 | Duplicate a file descriptor (dup → lowest free fd; dup2 → specified fd) | 複製描述符 | Lab/PA1 |
| EDF | Earliest-deadline-first: dynamic priority, earlier deadline = higher priority; theoretically optimal | 最早截止期限優先 | 5.51 |
| Exec() | Replaces the current process image with a new program; returns only on failure | 執行新程式 | 3.41 |
| Exponential averaging | $\tau_{n+1} = \alpha t_n + (1-\alpha)\tau_n$: predicts the next CPU burst | 指數平均 | 5.19 |
| FCFS | First-come first-served; non-preemptive; convoy effect | 先到先得 | 5.9 |
| fork() | Creates a child duplicating the parent's address space; returns 0 to child, child PID to parent, −1 on failure | 分叉 | 3.35–3.37 |
| Hard affinity | Process specifies the subset of CPUs it may run on | 硬親和性 | 5.45 |
| Hard real-time | Task must be serviced by its deadline; late = no service | 硬實時 | 5.47 |
| Heap | Memory dynamically allocated at run time | 堆積 | 3.5 |
| Hybrid system | OS combining several structures (Linux, Windows, macOS) | 混合式 | 2.52 |
| Indirect communication | Messages sent to/received from mailboxes (ports) | 間接通訊 | 3.60 |
| Interrupt | Signal from hardware/software requiring CPU attention; handled by an ISR | 中斷 | 3.21–3.24 |
| Interrupt vector | Table of interrupt-handler addresses indexed by interrupt number | 中斷向量 | 3 (summary) |
| I/O-bound process | Spends more time on I/O; many short CPU bursts | I/O 密集 | 3.14 |
| IPC | Mechanism for cooperating processes to exchange data: shared memory or message passing | 進程間通訊 | 3.51 |
| Kernel | The one program running at all times on the computer | 核心 | 1.24 |
| Kernel thread | Thread supported and scheduled by the OS | 核心執行緒 | 4.19 |
| Layered approach | OS divided into layers (0 = hardware … N = UI); each uses only lower layers | 分層結構 | 2.44 |
| Linker | Combines relocatable object files and libraries into one executable | 連結器 | 2.31 |
| Little's formula | $n = \lambda \times W$ (queue length = arrival rate × waiting time) | 利特爾公式 | 5.57 |
| Load balancing | Keep workload evenly distributed across CPUs (push / pull migration) | 負載平衡 | 5.46 |
| Loadable kernel module (LKM) | Core kernel plus modules linked in at boot or run time; any module can call any other | 可載入核心模組 | 2.49–2.50 |
| Loader | Loads the executable file into memory for execution | 載入器 | 2.31 |
| Locality (temporal / spatial) | Recently accessed items are reused soon / nearby items are accessed soon | 局部性 | 1.33 |
| Long-term scheduler (job scheduler) | Selects which jobs are brought into memory; controls degree of multiprogramming | 長期排程器 | 3.17 |
| LWP (lightweight process) | Virtual processor between user threads and a kernel thread | 輕量級進程 | 5.36 |
| Many-to-one / one-to-one / many-to-many | Mappings from user threads to kernel threads | 多對一 / 一對一 / 多對多 | 4.21–4.24 |
| Medium-term scheduler | Swaps processes out to disk and back to reduce degree of multiprogramming | 中期排程器 | 3.18 |
| Memory stall | Processor waits for data from memory (e.g., cache miss) | 記憶體停頓 | 5.40 |
| Message passing | IPC via explicit send()/receive() without shared memory | 訊息傳遞 | 3.57 |
| Microkernel | Minimal kernel; other services run in user space and communicate via message passing | 微核心 | 2.46–2.48 |
| MLFQ | Multilevel feedback queue: processes move between queues; approximates SRTF without burst knowledge | 多級回饋佇列 | 5.30–5.35 |
| Mode bit | Hardware bit: 1 = user mode, 0 = kernel mode | 模式位元 | 3.28 |
| Monolithic | All kernel functionality in one static binary in a single address space; fast but hard to maintain | 單體式 | 2.41 |
| Multicore | Multiple computing cores on a single chip; faster on-chip communication, less power | 多核心 | 1.39 |
| Multilevel queue | Processes permanently assigned to queues by type; each queue its own algorithm | 多級佇列 | 5.28–5.29 |
| Multiprogramming | Keeping several jobs in memory so the CPU always has one to execute | 多道程式 | 1.42 |
| Mutex lock | Lock acquired before and released after a critical section (acquire/release atomic) | 互斥鎖 | 6.22 |
| Mutual exclusion | If one process is in its CS, no other process can be in its CS | 互斥 | 6.11 |
| Named pipe (FIFO) | Bidirectional (UNIX half-duplex) pipe with a file name; no parent–child needed; persists until deleted | 具名管道 | 3.69 |
| Non-preemptive scheduling | Process keeps the CPU until it terminates or blocks | 非搶佔式 | 5.6 |
| NUMA | Each CPU has fast local memory; remote memory access slower | 非一致記憶體存取 | 1.40 |
| Ordinary pipe | Unidirectional pipe between parent and child; fd[0] read, fd[1] write; gone after use | 普通管道 | 3.66 |
| Orphan | Child whose parent terminated without wait(); adopted by init/systemd | 孤兒進程 | 3.50 |
| Parallelism | Performing more than one task simultaneously (needs multiple cores) | 平行 | 4.9 |
| PCB | Process control block: state, PC, registers, scheduling, memory, accounting, I/O info | 進程控制塊 | 3.10 |
| PCS (process-contention scope) | Thread library schedules user threads onto LWPs, among threads of the same process | 進程競爭範圍 | 5.37 |
| Pipe | IPC channel treated as a special file; read()/write() | 管道 | 3.65 |
| Policy vs mechanism | Policy = what will be done; mechanism = how to do it | 策略與機制 | 2.34 |
| Preemptive scheduling | CPU can be taken away involuntarily (interrupt, higher-priority arrival) | 搶佔式 | 5.6 |
| Priority scheduling | CPU to highest-priority process (smallest number); starvation → aging | 優先權排程 | 5.25 |
| Privileged instruction | Instruction executable only in kernel mode (I/O, timer, interrupt management) | 特權指令 | 3.28 |
| Process | A program in execution; active entity with PC and resources | 進程 | 3.4–3.5 |
| Processor affinity | Tendency to keep a process on the CPU whose cache holds its data | 處理器親和性 | 5.45 |
| Program | Passive entity — executable file on disk | 程式 | 3.5 |
| Progress | If no one is in the CS, selection of the next entrant cannot be postponed indefinitely | 前進 | 6.11 |
| Pull / push migration | Idle CPU pulls tasks / a task pushes work from overloaded CPUs | 拉 / 推遷移 | 5.46 |
| Race condition | Outcome depends on the order of concurrent access to shared data | 競爭條件 | 6.9 |
| Ready queue | Processes in memory ready and waiting to run | 就緒佇列 | 3.15 |
| Rate-monotonic (RM) | Static priority = shorter period higher priority; optimal among static-priority algorithms | 速率單調 | 5.49 |
| Response time | (Course) end of the first run − arrival; time until the first response is produced | 回應時間 | 5.12 |
| Round robin (RR) | FCFS with a time quantum; preempted process to tail; wait ≤ (n−1)q | 輪轉 | 5.11 |
| RPC | Remote procedure call: message-based procedure call between networked systems | 遠端程序呼叫 | 3.70 |
| SCS (system-contention scope) | Kernel schedules kernel threads onto CPUs, among all threads in the system | 系統競爭範圍 | 5.37 |
| Semaphore | Integer accessed only via atomic wait() (P) and signal() (V) | 信號量 | 6.24 |
| Shared memory | IPC by reading/writing a shared region | 共享記憶體 | 3.51 |
| Signal | UNIX notification to a process that an event occurred | 信號 | 4.29 |
| SJF | Shortest-job-first: optimal minimum average waiting time; hard to know next burst | 最短工作優先 | 5.17 |
| SMP | Symmetric multiprocessing: each processor self-schedules; own registers & cache, shared memory | 對稱多處理 | 1.38, 5.39 |
| Socket | Endpoint for communication identified by IP address + port | 套接字 | 3.70 |
| Soft affinity | OS tries but does not guarantee to keep a process on the same CPU | 軟親和性 | 5.45 |
| Soft real-time | Critical tasks get preference over non-critical ones; no guarantee | 軟實時 | 5.47 |
| Spinlock | Lock that busy-waits; no context switch, wastes CPU; good for short CS on multiprocessors | 自旋鎖 | 6.22 |
| SRTF | Shortest-remaining-time-first: preemptive SJF | 最短剩餘時間優先 | 5.23 |
| Stack | Temporary data: function parameters, return addresses, local variables | 堆疊 | 3.5 |
| Starvation | A process waits indefinitely (low priority / semaphore queue) | 飢餓 | 5.25, 6.28 |
| System call | Programming interface to OS services | 系統呼叫 | 2.14 |
| System program | Utilities shipped with the OS providing a convenient environment (not part of kernel) | 系統程式 | 2.27 |
| Task parallelism | Different threads performing unique operations on cores | 任務並行 | 4.11 |
| TCB | Thread control block: registers, PC, stack pointer, scheduling info, pointer to PCB | 執行緒控制塊 | 4.15 |
| Test-and-set | Atomically returns the old value of a boolean and sets it to TRUE | 測試並設置 | 6.15 |
| Thread | Basic unit of CPU utilization: thread ID, PC, register set, stack | 執行緒 | 4.6 |
| Thread-local storage | Data unique to each thread | 執行緒區域儲存 | (Sp21 MC) |
| Throughput | Number of processes completed per unit time | 吞吐量 | 5 (summary) |
| Timesharing (multitasking) | CPU switches among jobs so frequently that users can interact with each | 分時 | 1.42 |
| Trap / exception | Software-generated interrupt caused by an error or a system call request | 陷阱 / 例外 | 3.24, 3.31 |
| Turnaround time | Completion time − arrival time | 周轉時間 | 5.8 |
| User thread | Thread managed by a user-level library, invisible to the kernel | 使用者執行緒 | 4.19 |
| Virtualization | Abstracts one computer's hardware into multiple execution environments (VMs) | 虛擬化 | 1.43 |
| VMM / hypervisor | Creates and manages VMs, presenting an interface identical to the host | 虛擬機監控器 | 1.44 |
| von Neumann architecture | Stored-program: instructions and data in the same memory; fetch–decode–execute | 馮紐曼架構 | 1.26 |
| Waiting time | Time spent in the ready queue = turnaround − burst | 等待時間 | 5.8 |
| Zombie | Terminated process whose parent has not yet called wait(); PID & PCB remain | 殭屍進程 | 3.49 |
